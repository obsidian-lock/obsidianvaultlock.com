Install

  1. 1

    Get Obsidian

    Free for Windows, macOS and Linux.

    Download
  2. 2

    Add BRAT

    In Obsidian, open Settings → Community plugins, browse for BRAT, then install and enable it.

  3. 3

    Add Vault Lock

    Press Install and BRAT adds it to Obsidian. Or choose Add beta plugin in BRAT and paste:

    obsidian-lock/vault-lock
    Install

On first start, Vault Lock asks you to choose a passphrase. That's it.
