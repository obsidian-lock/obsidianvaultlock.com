Vault Lock

A passphrase lock screen for Obsidian, with a private folder that disappears while the vault is locked.

Install with BRAT View on GitHub

Free and open source. Obsidian 1.5 or newer. The button needs BRAT installed.

What it does

One job, done quietly. Lock the window, hide one folder, ask for the passphrase.

Locks when it should

At launch. After a number of idle minutes (five by default). When the window loses focus, if you turn that on. Or the moment you run Lock vault now. If Obsidian crashes while unlocked, it locks again at the next start, before the interface appears.

A real lock screen

While locked, an overlay covers the whole window and pop-out windows go blank. Hotkeys and the command palette don't work, the Settings window is closed, and every window title shows only "Obsidian".

A folder that disappears

On lock, tabs showing private notes are closed and the private folder (Private by default) is renamed to .Private. Obsidian ignores dot-folders completely: file explorer, search, graph and quick switcher. On Windows the folder also gets the hidden attribute.

The passphrase is never stored

Only a PBKDF2-SHA256 hash (200,000 iterations, random salt) is kept in the plugin's data.json. Each wrong passphrase adds a growing delay, up to five seconds.

Four settings

The passphrase. Lock after idle minutes (0 turns it off). Lock when the window loses focus. The private folder's name, changed only while unlocked. Nothing else.

Two commands

Lock vault now locks immediately. Set or change passphrase opens the passphrase prompt and asks for the current one first.

Desktop only: Windows, macOS and Linux. Obsidian 1.5.0 or newer.

Install

Vault Lock is not in the Obsidian community catalogue. BRAT installs it from GitHub and also installs updates. Three ways to get there, easiest first.

  1. 1

    One click

    If BRAT is already installed, press Install with BRAT. Obsidian opens and asks BRAT to add the plugin. If Vault Lock is not switched on afterwards, enable it under Settings → Community plugins.

  2. 2

    With BRAT, by hand

    1. Open Settings → Community plugins. If Obsidian shows Restricted mode, turn it off.
    2. Choose Browse, search for BRAT, then Install and Enable.
    3. In BRAT's settings choose Add beta plugin, paste obsidian-lock/vault-lock and press Add.
    4. Enable Vault Lock under Community plugins.
  3. 3

    Manual

    From the latest release download main.js, manifest.json and styles.css into <your vault>/.obsidian/plugins/vault-lock/. Reload Obsidian and enable Vault Lock under Community plugins. Those three files are the whole plugin. There is no other installer.

The button did nothing?
  • Obsidian must be installed and open. The button is an obsidian:// link, and only Obsidian can answer it.
  • BRAT must be installed and enabled first. Path 2 above shows how.
  • Vault Lock runs on the desktop only. Obsidian on phones and tablets is not supported.

What it is not

Vault Lock is a privacy screen, not a safe.

  • Nothing is encrypted. Your notes, the private folder included, stay ordinary files on disk, readable by anyone who can open them.
  • The lock is a file. Deleting the plugin's data.json removes the lock. Anyone who can reach that file can get past it.
  • For a lost or stolen laptop, use full-disk encryption: BitLocker, FileVault or LUKS. Vault Lock keeps casual eyes off the screen. It does not replace that.
